# Project contract

This repository is a standalone Rust rewrite of the CoD4X dedicated server.
Existing CoD4/CoD4X clients, maps, and mods are compatibility targets. ApX is a
future consumer, not a core dependency. Do not read or modify the Deathrun
workspace as part of this project. Do not use Graphify.

Remove inherited engine capacity ceilings through configurable storage and wide
internal identifiers. Legacy wire/client/asset-format bounds belong to named
compatibility profiles, never global engine allocation rules. Preserve the full
content catalog: the user's prior character/prestige/image cuts must not become
the new engine's design. Expanded client-visible capacity needs negotiated peer
support; never truncate IDs, silently remove content, or claim old clients can
represent unsupported features. Read docs/limits.md before designing storage.

Read README.md, docs/engineering.md, docs/architecture.md, docs/compatibility.md,
and docs/roadmap.md before changing the architecture or claiming compatibility.

Follow Google's Rust Style Guide, as adapted explicitly in docs/engineering.md.
GSC is a core expansion target, not merely a legacy VM port. Preserve existing
scripts through a compatibility mode; richer language features, built-in services,
asynchronous I/O, and developer tooling belong in the Rust engine and must not
require native CoD4X plugins. Keep extensions versioned and use wide runtime IDs/
configurable budgets. Read docs/gsc-runtime.md before designing this subsystem.
Do not claim GSC is implemented based on plans, content readers, or an empty crate.
Implement leaf modules, use explicit imports and typed errors, document public
APIs, and keep unsafe code forbidden. All crates must inherit workspace lints.
Do not add speculative crates, placeholder implementations, or unused abstractions.

Network and asset input is untrusted. Validate lengths before indexing or
allocation; enforce resource limits; do not panic on malformed input. Keep valid
wire behavior distinct from intentional changes to invalid-input behavior.

The pinned upstream revision and source hashes live in upstream.lock.json.
Preserve upstream provenance and license notices. Reference C/assembly is test
and research material; it must not become a runtime dependency of the Rust server.

--check; these do not execute original semantic actions or establish compilation.
That check also guards typed declaration action/production profiles. Preserve raw
declaration spelling/duplicates until verified name binding; see ADR 0017.
It also guards typed expression operator/wrapper roles. Preserve short-circuit
branches separately from eager infix operators. Operator views retain unresolved
primary descendants; local classification is not validation/evaluation. See ADR 0023.
Separate primary views now expose local literal/group/call/reference/object and
animation/debugger roles without converting, binding, or executing descendants.
Retain raw signed literal syntax and parenthesized lists; see ADR 0024.
Expression-list indices preflight both passes and complete count/metadata before
allocation. Source order does not establish native argument evaluation/push order;
see ADR 0025. Script tests use explicit frontend/legacy suites with small leaf files.
Register each new #[test] leaf in exactly one suite; repository policy guards
missing/duplicate/gated registrations, including subfolders. Use --test frontend
or --test legacy plus a module filter, not old standalone leaf targets; see ADR 0026.
Call/function-name views retain raw virtual paths, names, indirect expressions,
receiver and invocation modes. Argument lowering is separately budgeted; these
views grant no I/O/builtin authority and do not link, execute, or schedule. See ADR 0027.
Reference views preserve raw name/dollar/field/index/reserved .self roles. Do not
fold .self into ordinary .Self field syntax or infer writable slots/runtime
authority from a structural reference. Descendant walks need budgets; see ADR 0028.
The execution kernel owns immutable verified typed instructions for numeric/
undefined data only. Verify all targets (even unreachable code), reachable stack
joins/returns/fallthrough, and storage/work before proof publication. Execution
requires separate stack/fuel admission; failed work must remain charged. Do not
describe it as source compilation/full GSC execution or invent a serialized/native
bytecode ABI, object heap, scheduler, or host authority. See ADR 0029.
Restricted scalar source compilation now connects typed zero-parameter empty/
single-return bodies to owned code/maps. Reject unsupported syntax explicitly;
preserve lazy branches, source spans, live-task/compiler work/storage limits, and
separate kernel proof/validation budgets. No partial function/module activation
may escape failure. Checked signed MIN literal admission is an explicit domain
policy, not native atoi overflow parity. This is not general GSC compilation,
locals/calls/objects/scheduling/host services or stock-mod acceptance; see ADR 0030.
Typed statement views now preserve supplied and direct operation nodes, with
unresolved expression/reference/body/event/for-option children. Keep specialized
event argument profiles distinct from ordinary expression lists. Body indices
preflight both passes/count/storage before allocation, retain actual failed work,
and never flatten nested bodies. Syntax does not grant lvalue/control-flow scope,
developer activation, debugger/host authority, or scheduling. Guard statement/body
profiles via generate_syntax_tables.py --check; see ADR 0031.
Scalar kernel layouts now admit parameter/total-local counts and verify every local
operand, including unreachable code. Invocation uses fresh private slots with
separate local count/byte limits; uninitialized slots differ from stored Undefined.
Exact internal argument slices are not native GSC missing/extra-argument policy.
Retain runtime local checks, failed work/local admission, and caller isolation.
This adds no source local binding, call stack, definite-assignment proof, scheduler,
or host authority; the restricted source compiler remains unchanged. See ADR 0032.
A separate straight-line scalar-local source profile now binds parameters/plain
name assignments and checks initialization in source order, including skipped
source. Initialize new targets only after RHS lowering/store; preserve reassignment
and initialized Undefined. Admit binding count/identifier visits/logical map-pair
payload alongside compiler tasks/code; hash capacity/control/allocator overhead
and separately admitted body/kernel scopes are excluded, not aggregate RSS.
Reject unsupported control flow/targets/values, nonfinal returns and duplicate
parameters explicitly under this profile. Results tag the source profile and
optional validation steps; local-profile compilation must not run fabricated
arguments. This is not native arity/duplicate-parameter/whole-mod equivalence,
control-flow definite assignment, general GSC or activation. See ADR 0033.
Scalar-local source now includes the ten guarded compound assignments for
initialized plain names. Preserve prior target/RHS values, source token locations,
existing numeric semantics and compiler/name budgets. No compound read creates
an uninitialized binding; object/index targets and side-effecting RHS semantics
remain unsupported. Postfix integer-only updates stay separate; see ADR 0034.
Postfix plain-name statements now use an explicit integer-only value/kernel
operation. Preserve type rejection and wrapping word semantics, source update
spans, initialized-name admission and existing quotas. The pinned VM assembly
hash/profile guard ties grammar tags/compiler opcodes/type checks/instructions;
it does not execute native handlers or establish full reference/error/VM parity.
Keep the 0x86 VM dispatch versus 0x89 header debugger inventory distinction.
Regenerate source profiles and arithmetic vectors; see ADR 0035. Modern update
rules, postfix expressions/object references and control flow remain separate.
An explicit scalar legacy script-argument entry point now fills missing parameter
slots with initialized Undefined and rejects extras. Preserve source-parameter
order at this API, nonparameter uninitialized slots, exact/empty internal entry
point contracts, caller isolation and all existing local/stack/fuel limits. Fill
the admitted local vector directly without an unaccounted padded argument array.
Guard parameter walks, safe-set markers/consumption/checks and Undefined creation
through generate_syntax_tables.py --check. This is not builtin validation, native
evaluation/push order, call frames or full unwind/VM parity; see ADR 0036.
Scalar-local blocks and if/else now share stable wide slots and flat lowering.
Restore incoming facts before else; intersect only paths reaching the join and
retain source checks for both branches, including constant conditions. Preserve
immediate nonfinal-return rejection and reject structurally unreachable source.
Admit live snapshot flag bytes against control and total metadata quotas, charge
initialization/copy/restore/merge visits globally, and release exactly once. Bind
private conditional/unconditional relocations once and verify real targets before
publication. This restricted structural policy does not establish native scopes,
constant folding, diagnostic order, loops/switch or full compilation; see ADR 0037.
Scalar while now uses private backward labels and existing verified jumps/fuel.
Reevaluate conditions each iteration and check body source without constant
folding. Restore incoming initialization at the exit for zero-iteration safety;
reuse snapshot/task/work admission and original operation/keyword spans. Guard
selected while/compiler/VM roles via generate_syntax_tables.py --check, without
claiming native routine/watchdog timing/scope parity. For, break/continue, switch
and general runtime behavior remain separate work; see ADR 0038.
Scalar while break/continue now preserve nearest-loop contexts and terminate
their structural paths. Save outer context ownership in admitted flat tasks;
continue targets the actual condition and break chains link within complete
pending instruction records. Bind each link once with monotonic/forward checks
and global work charging. Reject illegal/unreachable source and retain keyword
maps/fuel; no unresolved link may publish. Keep emission/admission and relocation
binding/resolution in separate leaf modules. Guard selected native context/fixup/
restore roles without claiming native block cleanup/for/switch/VM parity; see ADR 0039.
Scalar for now lowers optional clauses in explicit phases through generalized
loop contexts. Deferred continue fixups target update start, with initialization
snapshots intersecting continuing body/fallthrough paths and excluding break/return.
Use existing snapshot/work/metadata admission, release facts once, and check
unreachable updates against incoming facts. Exits conservatively allow zero
iterations; clauses accept only scalar assignment/update/empty forms. Preserve
explicit restrictions rather than claiming native scope/constant-folding parity.
Guard selected optional grammar/compiler phases and retain wide flat ownership;
see ADR 0040. Switch/general values/calls/scheduling remain separate work.
Owned legacy vector helpers now preserve numeric broadcast, component operators,

Keep numeric-value dispatch in its own leaf. Source three-element groups remain

never use --target-dir, set CARGO_TARGET_DIR, or create separate preview/WSL build
caches. Before rebuilding, stop the old local development server after verifying
its executable belongs to this repository. Do not stop unrelated processes or
production servers. This explicit user authorization supersedes the earlier
local-development no-stop rule; remote deployment/administration stays separate.
On Windows run tools/stop-dev-server.ps1 before rebuilding the process. It checks
the exact repository-owned debug/release executable paths before stopping them.
Report what was verified, what remains unimplemented, and which acceptance gates
are still open. Passing round trips alone is not compatibility evidence.

Do not deploy, publish, or change a production server as part of local development.

Do not print credentials or commit private configuration or proprietary assets.
