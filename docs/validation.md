The primitive message sub-suite includes 12 boundary tests, one differential
integration test, and one documentation example. The differential test checks 64 independently
generated C packets containing 6,144 mixed operations. It decodes those packets
at all 21,458 storage split boundaries, including empty first/second slices.
Expected bytes are never generated by the Rust implementation under test.

Boundary coverage includes every bit width 0..32 at every initial alignment,
all invalid widths 33..255, exact capacity, truncation, atomic failures, cached
bits after byte exhaustion, backing-buffer reuse, 128 KiB limits, signed fields,
and special IEEE 754 binary32 representations.

The source-size policy was also exercised with a temporary 401-line Rust file;
it rejected the file, which was then removed. Largest handwritten source file:
233 lines. The largest generated source is a 287-line codebook. First-party Rust
forbids unsafe code; protocol has no third-party dependencies, and ordinary
transport depends only on protocol.

verified old development process before rebuilds. Native rechecks now follow
that policy; do not create alternate WSL/preview caches for future validation.
Both native platforms regenerated the same fixtures. CI is defined
for Windows and Linux but has not run on a hosted GitHub repository.

The expanded suite before pretty-log tests contained 71 native tests plus one
